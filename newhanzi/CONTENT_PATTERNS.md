# hanzi-app 内容模式规范 v2.0

> 理论基础：DITA（concept/task/reference）× Diátaxis（四象限）× Merrill信息类型论
> 核心：内容建模（分型）→ 每型一个模板 → 内容与呈现分离
> 定稿：2026-11-03，Lucas 批准

## 型一：规律型（机制类）

**对应**：DITA-concept / Merrill-概念+原理
**适用**：语法规则（把字句/被字句）、平仄、对仗、起承转合

**范式**：
```
啊哈现象（一个反直觉的例子抓注意）
→ 一句白话（核心规则，≤30字）
→ 图式/动画（可视化机制）
→ 例组（3-5个正例，分组）
→ 病例（2-3个典型错误+改正）
→ 口诀（一句话记忆）
```

## 型二：辨析型（易混对比）

**对应**：Merrill-概念（正例+反例）
**适用**：的地得、在/再、的/得、关联词辨析、近义词

**范式**：
```
对照表（左右对比，维度对齐）
→ 分水岭例句（一句定胜负的典型例）
→ 天坑病例（最易错的3个坑+爬出方法）
```

## 型三：程序型（做题步骤）

**对应**：DITA-task / Merrill-程序
**适用**：病句修改、翻译方法、阅读步骤、断句

**范式**：
```
步骤卡（1.2.3.，每步一句话+判断标准）
→ 决策树（if-then分支图）
→ 全程演示（一道题从头做到尾）
```

## 型四：词条型（单词页）

**对应**：DITA-reference / Diátaxis-参考
**适用**：识字卡、实词、虚词、部首

**范式**：
```
音（拼音+声调）
形（字形/部首+结构）
义（义项分组，按常用度，每义配2-3组词+1-2例句）
联系网（近义/反义/相关词）
```

## 型五：模式型（拼读/词缀/格律）

**对应**：Merrill-概念（图式习得）
**适用**：词牌格式、格律模式、句式结构、平仄格式

**范式**：
```
图式（可视化结构图，不用文字墙）
→ 成员词阵列（符合该模式的词/句，陈列）
→ 例句（2-3个完整实例）
```

## 型六：故事型（词源/背景）

**对应**：Diátaxis-解释
**适用**：字源、成语典故、诗人背景、古文背景

**范式**：
```
时间轴叙事（起因→经过→结果）
→ 关键节点（3-5个转折点）
→ 今义回扣（和今天的联系）
```

## 型七：材料型（对话/歌谣/篇目）

**对应**：Diátaxis-教程（沉浸）
**适用**：古文篇目、诗词原文、乐府歌谣

**范式**：
```
整段呈现（原文完整，语流优先）
→ 逐句锚点（点击每句看讲解，不破坏整体）
→ 结构退位（不强制分段，让位给语流）
```

## 型八：清单型（速查参考）

**对应**：DITA-reference / Diátaxis-参考
**适用**：常用字表、部首表、高频词、总表

**范式**：
```
表格化（高密度，行列对齐）
→ 行话退出（只用用户语言，不用术语）
→ 可筛选/检索
```

---

## 通用要求

1. **概念配例句**：至少5个（2026-11-03标准）
2. **去冗余**：各部分不重复
3. **字体规范**：解释无衬线15px深色行高2；例句衬线13px灰色、虚线分隔
4. **呈现分离**：数据按型打标，渲染器按型选模板（待实现）
