# hanzi-app 内容模式规范 v3.0（最终）

> 理论基础：DITA × Diátaxis × Merrill
> 核心：内容建模（分型）→ 每型一个模板 → 内容与呈现分离
> 定稿：2026-11-03，Lucas 批准（9型）

## 型一：规律型

**范式**：啊哈（类比/图示/动画）→ 一句白话（讲解+口诀+例组）→ 分类块 → 深讲 → 怎么认 → 辨析 → 例句解析 → 易错 → 动手练/题库

**主归属**：语法、诗词常识卡、古文规律7模块、逻辑

## 型二：辨析型

**范式**：对照表 → 分水岭例句 → 天坑病例

**主归属**：关联词、虚词、古今异义、一词多义、字卡"别认错"、部首常识区

## 型三：程序型

**范式**：步骤卡 → 决策树 → 一道题全程演示

**主归属**：病句、阅读、写作、翻译、诵读、赏析法、创作

## 型四：词条型

**范式**：音块 → 形块 → 义块 → 例句 → 联系网

**主归属**：字卡（主）、部首（主）、实词、名句典故、意象

**字卡附属**：故事型字源、辨析型别认错、模式型六书/形声、材料型文引用与诗句链

## 型五：模式型

**范式**：图式 → 成员阵列 → 例句（不要文字墙）

**主归属**：部首模式、六书模式、词类模式、词牌、格律

## 型六：故事型

**范式**：链条叙事（时间轴）→ 关键节点讲解

**主归属**：诗人小传、典故、诗史、字源、历史

## 型七：材料型

**范式**：整段呈现 → 逐句锚点 → 背景/赏析

**主归属**：诗库单首、古文篇目

## 型八：清单型

**范式**：表格/行列（密度可高，行话退出）

**导航分支**：卡片网格 + 计数

**主归属**：导航页、速查表、总表、体裁、流派、文化

## 型九：互动型（新增）

**范式**：一句话目标 → 可操作演示 → 即时反馈 → 计分/错题收录

**主归属**：lab、games、quiz

---

## 施工顺序

1. 清单型（导航+速查）：改动最小，先立"行话退出"标杆
2. 词条型（字卡+部首）：先修数据管道（音块/笔顺），再改模板
3. 规律型（yuwen语法→logic→古文规律7模块）
4. 辨析型：需内容增补（分水岭例句、天坑病例）
5. 程序型：需先恢复阅读/写作30点上线
6. 模式型+故事型：依赖图式/动画能力
7. 材料型：缺逐句锚点交互
8. 互动型：题库互通放最后
