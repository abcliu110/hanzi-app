## (a) 现状一句话诊断

**文字内容和题库已经够厚（15 个专题 × 10 例 + 211 题，带干扰项误解标注），但“看得见的逻辑结构”几乎是零**：现有动画只是“高亮词块 + 换一行说明”，图示是写着文字的静态 SVG；没有一个逻辑专题接入已经很成熟的 wb 白板引擎，练习全是点选，孩子从头到尾没有亲手“摆一摆”逻辑结构的机会。

### 现状要点（读代码所见）

**强项**
- **内容结构完整**：每个专题都有 目标 / 类比 / 讲解 / 口诀 / 例子（每专题 10 条）/ 深讲 / 怎么认 / 辨析 / 例句解析 / 易错 / 练习（各 3 题）。lessonHtml 里有“先试试”：把练习第 1 题提到讲解前面，先做题再看讲解，方向是对的。
- **题库质量高**：211 题分 8 种模式：choice 60 / judge 40 / spot 30 / tag 20 / order 20 / blank 20 / rewrite 20 / match 1。choice 题带「误解标注」，按干扰项写出误解和正反例，这是国外产品里也少见的诊断式设计。错题本 + SRS 也已经接上。
- **素材本土化**：用了白马非马、樊锦诗、死难者里“幸免”的病句、苏格拉底三段论等，贴近语文课和中考、高考语境。
- **白板引擎可以直接复用**：`wb-engine.js` 已有 12 个模板（title / cards / test / mark / vs / slots / fix / link / rel / steps / line / end）。画面只由时间 t 决定，可以拖进度条；旁白按 3.5 字/秒排时长；`ask` 拍先停 4 秒让孩子想一想；有章节 tab、朗读开关，用 rough.js 画手绘线。语法已经做了 99 个场景文件，其中包括 `bj_luoji.js`（不合逻辑）。设计文档里还规划了 `nest` 套盒子、`morph`、`trunk` 等新模板，正好能借来画逻辑结构。

**弱项**
1. **动画播放器有缺陷**：index.html 的逻辑动画只渲染 `steps[0].tokens`。后面几步的 tokens 从来不显示，只换说明文字，高亮下标也被截在第一步的词块数以内。比如「三段论」第 2、3 步的“小前提 / 结论”词块根本不出现。15 个专题里只有 7 个有 `动画`，5 个有 `图示`，图示又多是“三行字的 SVG”（三段论图示就是三行文本加一条横线）。
2. **没有接入 wb 白板**：`NHZ_WB_INDEX` 里没有任何逻辑专题。yuwen.html 按 `it.name` 去查这个索引，所以逻辑页永远不会出现“▶ 播放白板动画”。index.html 的逻辑面板走的是另一套 lessonHtml，也不认 wb。
3. **缺少结构化图式**：没有欧拉图 / 维恩图、论证树、条件箭头链、真值格。CONTENT_AUDIT.md 自己也标了“⚠️ 缺图式 / 缺决策树”。
4. **练习只能点选**：tag / order / match 也都是点。没有拖圆圈、搭论证、翻牌验证这类“操作结构”的题型。match 模式只有 1 题。题目也没有专题标签，从课文跳不到“本专题专练”。
5. **知识点缺口**（对照统编高中选择性必修上册第四单元《逻辑的力量》）：充分 / 必要条件、隐含前提、反证法 / 归谬法 / 排除法、“虚拟论敌”在 logic.json 和题库里都是 0 次；概念间关系（全同 / 包含 / 交叉 / 全异）也没有。专题之间有重复：“因果链”和“因果链：多米诺”分成两个专题；“常见谬误”一个专题塞了十几种谬误。
6. **缺情境叙事**：所有例子都是孤立的一句话，没有“侦探 / 法庭 / 吵架”这种连续情境，难以迁移到孩子真实听到的广告和网络句子。

## (c) 提炼出的设计模式

| 模式 | 一句话 | 来源 | 适用专题 |
|---|---|---|---|
| **M1 套圈判官（欧拉 / 维恩拖拽判定）** | 每个概念是一个圈，前提决定圈怎么套；摆完前提后，如果“结论自动成立”就有效，否则举出反例摆法。 | Brilliant、Edukalc、Wolfram | 三段论、概念关系、偷换概念、以偏概全 |
| **M2 找反例 = 判无效** | 不背规则，只问一句“能不能让前提都对、结论却错？”能造出来就无效。 | Wolfram Lewis Carroll 图、Wason | 三段论、条件推理、强加因果 |
| **M3 翻牌验证（真值格）** | “如果 P 就 Q”只怕“P 且非 Q”；翻的牌落进 2×2 格，孩子一眼看到哪一格才是“抓现行”。 | Wason 2.0 | 条件推理、充足理由律 |
| **M4 谬误卡牌 + 家族树** | 一张卡 = 图标 + 一句话定义 + 一个例子 + 识别口令；卡片按家族归类，可收集，可“出牌点名”。 | YLFI、Bad Arguments | 常见谬误、以偏概全、强加因果、自相矛盾 |
| **M5 对照案件（同线索，不同推理）** | 两个人拿同样的证据，一个推对、一个推错，差别只在推理形式。 | 统编教材 袁滋 vs 过于执 | 条件推理、推理三兄弟 |
| **M6 侦探情景剧** | 连续剧情 + “暂停，你先推” + 逐步揭晓。 | TED-Ed、Brilliant「理性侦探」 | 推理三兄弟、言外之意、因果链 |
| **M7 论证地图** | 论点在顶，理由挂下面，反驳挂旁边；能投“这条理由有多强”。 | Kialo、Rationale | 举例 / 道理 / 对比论证、虚拟论敌、隐含前提 |
| **M8 规则即积木** | “所有 / 有的 / 不 / 是”做成可以推的词块，改一块，看图和结论怎么变。 | Baba Is You | 四大规律、三段论量词 |
| **M9 每日一句诊断** | 1 分钟一条真实句子（广告、标语、作文、网络话），找毛病、说原因、改一句。 | B站一分钟练习、统编“日常话语中的逻辑错误” | 全部谬误类 + 言外之意 |
| **M10 提问—反例—再提问** | 每课结束抛一个开放问题，要求“举一个反例”“说出你的理由”。 | P4C、TED-Ed Discuss | 所有专题收尾 |
