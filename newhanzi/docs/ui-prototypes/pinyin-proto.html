为什么偏右（所有模块都这样）

首页 index.html 的模块视图 #view-module .app-main 吃到了 zika.css 里 .page-home .app-main 的网格（2026-11-03 首页重设计 0a0ba775 加的）：≥768 时列为 260px + 1fr，区域「top / mods / hero board」；≥1200 时列为 280px + 1fr，max-width:1200px; margin:0（不居中）。

所有模块面板（.panel-frame 七个 iframe 模块，加识字、逻辑）都被放进 grid-area: board，也就是右列。左边的 hero 列本该放英雄卡，但 index.html 里已经没有 .hero-card，于是左边永远空 260–280px。

实测（Playwright）：768 宽时面板 x=300、宽 444px；1280 宽时面板 x=324、宽 848px，右边还空 80px。iframe 里的子页按 iframe 自己的宽度判断断点：444px 连平板档（768）都进不去，848px 进不了桌面档（1200），所以 1280 桌面上拼音菜单只有两列。

建议修法（等负责人定，原型已按此演示）

① 首页：模块视图不用那张网格，居中放满：

@media (min-width:768px){
  .page-home #view-module .app-main{
    display:block; max-width:1200px;
    margin:0 auto; padding:0 24px 32px;
  }
}

修后 iframe 宽度：768 → 720px，1280 → 1152px。仍然小于子页的 768 / 1200 断点，所以只改首页不够。

② 子页：菜单列数改用容器宽度判断（container-type:inline-size + @container (min-width:880px) 三列），不再看视口。平板 720 → 2 列；桌面 1152 → 3 列；iPad 横屏 1024 → 3 列。

③ 卡片对齐：卡片是 <button>，网格把同一行的卡片拉成一样高，而 button 默认把内容垂直居中，内容短的卡片（右列「单韵母」等）标题就往下沉；L 标签又是 float，和编号徽标不在同一行。改为 display:flex; flex-direction:column; justify-content:flex-start，标题行 flex 对齐，L 标签 margin-left:auto。

其他子页（部首、古诗、语法、实验、阅读、古文）同样受①影响；它们里面的断点也是按视口写的，修①之后要逐页看是否也要改成容器查询。

轻声L2

轻声读得又轻又短，书上不标调号。比如「妈妈」māma，第二个「妈」就是轻声。

轻声没有单独录音（audio-cmn 不含轻声），要靠词语录音来教，见 C 大纲「变调、轻声、儿化」。

依据：《汉语拼音方案》声调符号部分「轻声不标」；GB/T 16159-2012 第 6.5.1 条。

五度标记法L3
55阴平：从 5 度到 5 度，高而平。
35阳平：从 3 度升到 5 度。
214上声：先降到 1 度再升到 4 度，是最长的一个。
51去声：从 5 度一路降到 1 度。

上声只在单念、或在词语和句子末尾时读完整的 214；在一声、二声、四声和轻声前面，常常只读前半段的低降（半上，约 211 / 21）。两个上声相连，前一个读得像阳平（214 → 35）。

轻声没有固定的调值，读多高要看前一个字的声调。轻声是四声的一种音变，不是第五个声调。

依据：赵元任五度标记法（普通话调值 55 / 35 / 214 / 51 为通行描写）；上声变调与轻声见普通话水平测试实施纲要（调研报告 A9、A11）。

声母发音部位怎么出声气流
b双唇：上下嘴唇合拢嘴唇突然张开，「爆」出来不送气
p双唇和 b 一样爆开送气：有一股气冲出来

依据：《汉语拼音方案》声母表；普通话声母按发音部位、发音方法的通行分类。

一个字母三种读法L3

名称音：字母表里给字母起的名字，b 叫 bê。呼读音：教声母时为了好听清，在后面加个元音，b 读「玻」bo，又轻又短。本音：声母自己的音，只有嘴唇一开的那一下，几乎听不见。

拼读时用的是本音。所以拼 bā 不是「玻 + 啊」——要是把 bo 读满再接 a，就拼成「播啊」了。

普通话的 b 和 p 都是清音，区别在送不送气，不在声带振不振动（和英语的 b/p 不同）。

bo po mo fo 是省写：实际读的时候 b 和 o 之间有一点圆唇的过渡，有学者主张写成 buo，这是学界讨论，不作定论。

依据：《汉语拼音方案》字母表（名称音）和声母表（呼读字 玻 坡 摸 佛）；呼读音与本音之分、音节本位的讨论见调研报告 §3.1；单韵母 o 读音见教育部新闻办 2023 年答复（A8）。

手掌试一试：b 和 p 哪里不一样L1

把手掌（或一条薄纸条）放在嘴前一拳远。先读 b，再读 p。

读 p 时有一股气冲到手心，纸条被吹起来；读 b 几乎没有气。

依据：教育部《汉语拼音的教学特色》：送气和不送气，手放在嘴前成对比较（调研报告 A7）。

送气不送气，一共 6 对L2

b/p 是第一对。以后还会学到 d/t、g/k、j/q、z/c、zh/ch，都是「左边不送气、右边送气」。
