## 局限（请负责人知悉）
1. **audio-cmn 只有单音节**：没有词语、轻声、儿化、半上录音。变调用「单字原调 vs 实际读音」两个单音节按钮代替，按钮文字已写明「放进词里要连着读」；半上（211）、轻声、儿化、「啊」的音变都只能文字说明，无法真实播放。要真播放需要词语录音（edge-tts + 人耳复核，或自录），见 pinyin-05 待决问题。
2. **儿化词点读**：校验脚本允许 `huār` 这种儿化音节占两个字。渲染时若按 `S.parse('huār').audio` 播放会播 hua1（不带儿化），建议框架对 erhua 音节不播或标「基本音」。
3. **verse.real 按字映射**：同一首里同一个字只能有一种实际读音，所以儿歌都避开了同一字两种变法（如同首里「一个」和「一天」）。
4. **o1 录音**：易混音里 ō / ōu / wō 对比用了 cmn-o1，是否接近「喔」需人耳确认（同 pinyin-05 C1 的待决项）。
5. **anim**：`nasal` 框架未实现，靠 fallback；`tone-road` 的 params 字段是我拟的。
6. **mirror** 只用了 base 'b'（校验对非 b/d/p/q 只给提示）；n/u 翻转用口诀和找一找代替。
7. 方言成因只做概括，没有写具体到省份的结论。
