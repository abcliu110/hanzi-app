## 术语口径（需负责人知悉）
- 「他跑得很快」一类：本稿按刘月华等《实用现代汉语语法》（增订本）叫**状态补语**；现有「补语」正文把它算作程度补语。本组「程度补语」只指 极了 / 得很 / 坏了 / 死了 一类。两种叫法在中小学教材里都见过，程度补语条目的易错点里已写明，制作时旁白要说清。
- 「小狗累坏了（程度）/ 杯子摔坏了（结果）」放在程度补语 L3，取自设计文档 §4.5 的自编例。
