## 原型说明（请负责人审这一节）

**选点**：形容词使动用法 ·「必先苦其心志」（《生于忧患，死于安乐》，本 App 篇目）。理由：①例句在我们 59 篇里、本篇「重点」已注「苦：使……痛苦」；②使动是活用里最典型、最常考的一类；③天然有「最小对比」的错改（使动 vs 意动，知识库「什么是词类活用」易错原文就写着「把使动和意动混淆」）。

**看哪里**：古文 → 语法 → 词类活用 → 形容词使动用法 → 「🎬 白板动画 ▶ 播放」；同一详情页「看图说话」是新图示。

**幕表（3 幕，61 秒；规范 ≤ 约 60 秒/段）**

|---|---|---|---|
| 1 苦其心志（lv1） | **huo（新）** | 30 s | 读句 → 「苦」戴蓝三角帽（形容词）→ 想一想「“苦”后面跟着什么？」→ 其心志 画宾语波浪线 + 「宾语」标签 + 小字「他的内心」→ 想一想「形容词带了宾语，这个“苦”什么意思？」→ 旧帽挪到左边变淡、箭头指向新帽红圆（动词），「苦」变红、画谓语单线、标「谓语 · 使动」，下方出「使……痛苦」→ 展开行「(使) 其心志 苦」（「使」打枢纽圈）→ 今译「使他的内心痛苦」✓ |

**符号设计：词性 → 岗位**（与语法区同一套蒙氏符号和成分线，不新造颜色）
- 词性帽 = 蒙氏符号：▲蓝 形容词、●红 动词（名词 ▲黑，后续名词活用同法）。帽子回答「它本来是什么词」。
- 岗位 = 成分线（成分墨）：谓语单下划线、宾语波浪线、状语〔〕（名作状用）。成分线回答「它在句中站什么岗」。
- 活用 = **帽子没变的词站到了别的岗上 → 帽子换成新岗位要的词性**：旧帽左移变淡（保留「本来是形容词」的痕迹）、灰箭头、新帽画上、字变成新词性色、释义用强调色写在字下。这样「活用」就是一个看得见的动作，而不是一句术语。
- 展开行：把「使/以…为/为…」这类今译骨架写成一行，补出的字打枢纽圈（「使」），再读今译 ✓——对应翻译法「补」。
- 错改：用现成 `review`（同学的答案 → ✗ 圈错 → 正解 ✓ → 规则），专打最常见混淆（使动↔意动）。

## 待核（不进动画 / 待负责人或 GW 线定）

1. 「苦」释义三处措辞不一：guwen.js 本篇重点「使……痛苦」、译意「让他心志痛苦」；guwen_knowledge.js 形容词使动用法析「使……受苦」；人教注释「使他的思想痛苦」、教参「使他的内心痛苦」。原型用教参「使他的内心痛苦」、释义用篇目「使……痛苦」。
2. 语法「宾语」图示：「何 / 宾语 · 陋 / 宾语 · 之 / 标志 · 有 / 动词」把「何」「陋」分开各标宾语，宾语应为「何陋」整体（知识库宾语前置条：「“之”把“何难”提到“有”前」）。未改（属 F2/GW 数据）。
3. 「甚矣，汝之不惠」（gw_daozhuang、通假「惠」）不在本 App 59 篇原文里（出自《愚公移山》，本 App 未收），动画里没标篇目，可接受；若要「例句只取本 App 篇目」需换句。
4. 7 个活用点的知识库例句不在本 App 篇目里（见原型表）。
