# newhanzi · 前端 UI 规范

适用范围：`newhanzi/` 下全部页面（`index.html`、`zika.html`、`bushou.html`、`shici.html`、`yuwen.html`、`grammar_lab.html`、`proto-yuwen.html` 等）及 `zika.css`。

与 Figma「识字星球」护眼方案对齐：每个页面都要做护眼色 + 平板/桌面，不只首页。

## 1. 颜色 Token

权威定义见 `zika.css` 顶部 `:root`：

| Token | 亮色 | 用途 |
|---|---|---|
| `--bg` | `#e4eedf` | 页面底 |
| `--card` | `#f2f6ee` | 顶栏/主卡片底 |
| `--surface` | `#f8faf5` | 更浅表面 |
| `--ink` | `#2c3328` | 正文 |
| `--muted` | `#6b7566` | 次要文字 |
| `--accent` | `#4a7a59` | 主强调 |
| `--accent-deep` | `#3d5a40` | 标题、深按钮 |
| `--accent-soft` | `#d3e5d6` | 浅底、芯片 |
| `--line` | `#d5dfd0` | 描边 |
| `--leaf` | `#9ed0ad` | 轻装饰 |
| `--green` / `--blue` / `--red` | `#3f8e6b` / `#4a7a8c` / `#b85a52` | 语义色（蓝为青灰，非亮蓝） |

深色模式：跟随 `prefers-color-scheme: dark`（见 `zika.css`），勿另起一套高对比霓虹色。

禁止主色：奶油纸 `#F5F1E6` / `#FBF8EF`；亮蓝紫 `#4f7cff` / `#eef2ff` / `#3730a3`。

## 2. 断点

| 断点 | 要求 |
|---|---|
| 默认 | 平板单列/双列，大字号、大按钮（不支持手机，2026-11-04 负责人决定） |
| `≥768px` | 平板：多列网格、收紧过大 hero、侧栏/双栏按页启用 |
| `≥1200px` | 桌面：内容 `max-width` 约 1100–1200px 居中或双栏；字卡等详情可并排 |

子页（部首/古诗/语法/实验）必须带与首页同一套 `@media (min-width:768px)` / `1200px`，禁止只有首页响应式。

## 3. 布局注意

- CSS Grid 子项默认 stretch：hero / CTA 区域用 `align-self: start`，避免平板上被拉高。
- 重复 CTA：桌面若侧栏已有入口，隐藏 hero 内重复按钮。
- 顶栏 sticky；返回与标题层级清晰。
- 焦点：`outline: 3px solid var(--accent)`。

## 7. 导航（返回与前进）

全站所有页面的返回和前进使用同一套设计。这是硬性规则，新页面和改动页面都必须遵守。

**7.1 返回**

- 每个页面只有一个返回入口：顶栏最左边，文字统一为「← 返回」。
- 返回回上一级，不回首页。只有在模块最外层（如首页下的一级页面）时，返回才回首页。
- 页面内容区不再另放返回按钮（如「← 返回诗库」「← 返回实验室」「← 返回列表」）。层级返回由顶栏承担。
- 没有顶栏的独立页面，由 `nav-up.js` 显示「← 返回上一层」（有顶栏则放在顶栏最左侧，无顶栏则放左下角）。

**7.2 面包屑（前进的层级显示）**

- 顶栏标题显示当前层级，如：古文 › 语法 › 实词。
- 面包屑中的每一级都可以点，点哪一级就回到哪一级。最后一级是当前页，不可点。

**7.3 只用界面层级，不用浏览器历史**

- 禁止使用 `history.back()`、`history.go()`、`history.pushState()`、`history.replaceState()`、`popstate` 实现页面导航。
- 子页（iframe）声明自己的层级：`NHZNavPage.set(['一级名', '二级名'], [回一级的函数, null])`。
- 首页用 `postMessage` 向子页发送 `up` / `go` 命令；子页收到后回到指定层级。
- 首页支持 `index.html?m=模块名` 直接打开对应模块，供其他页面返回时使用。

**7.4 测验页**

- 做题或结算中，返回先回「选模式」页；已在选模式页，返回到来源页（链接带 `from=页面名`，缺省回首页）。
- 所有进入测验的链接都要带 `from` 参数。

**7.5 验收**

- 每个页面打开后，顶栏只有一个返回；内容区没有返回按钮。
- 进入两级以上的页面后，点返回能回到上一级，点面包屑能回到对应层级。
- 测试中不得出现 `history.` 的导航调用。
- Playwright 冒烟测试覆盖：进入、进二级、返回、面包屑。
