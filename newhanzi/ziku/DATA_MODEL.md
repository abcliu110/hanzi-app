# newhanzi 字库数据模型（v1）

## 一、字集范围：通用规范汉字表·一级字表（3500字）

**依据**（教育部权威文件）：
- 《通用规范汉字表》（国发〔2013〕23号）：一级字表 3500 字，"主要满足基础教育和文化普及的基本用字需要，也可以作为义务教育阶段的识字标准"
- 教育部：义务教育阶段"累计认识常用汉字3500个"；普通高中语文课标总目标"认识3500个左右常用汉字"——高中不新增识字量
- **结论：高三及以下 = 一级字表 3500 字**

文件：`ziku/ziku-level1-3500.json`

## 四、覆盖率（3500字，补数据+辅助字段升维后）

| 维度 | 覆盖 | 方法与来源 |
|---|---|---|
| 读音 | 100% | gsc_pinyin.csv + Unihan kMandarin |
| 笔画 | 100% | gsc + Unihan kTotalStrokes |
| 部首 | 99.9% | gsc + Unihan kRSUnicode |
| 繁体 | 99.9% | gsc |
| 六书 | 55.1% (1930) | 老app struct + 说文段注"六書為XX" + 教科书级象形/指事curated + IDS声旁谐音推断（算法） |
| 结构（独体/合体+间架） | 100% (3500) | 老app struct + cjkvi-ids 部件分解推断 |
| 字→词→句→文 | 99.9% (3496) | 老app senses（3236字）；264缺字中260字由 CC-CEDICT 补组词（句/文待补） |
| 笔顺动画+描红 | 100% (3500) | hanzi-writer-data（MIT）笔顺SVG全覆盖 |
| 字源 | 88.0% (3079) | 说文解字+段注（简繁映射）；老app evo 演变阶段框架 |
| 形近字 | 87.3% (3055) | 30组经典形近字curated（人工）+ 老app codes + IDS同部件挖掘（算法初筛） |
| 形声拆解 | 92.5% (3236) | 老app parts |
| 易错提示 | 73.4% (2569) | 老app misread |

补数据脚本：`ziku/build_model.py`（基线）→ `ziku/fill_gaps.py`（补缺口）→
`ziku/promote_aux.py`（辅助字段升维+切分单字文件到 `data/zika/`）。

老app字集 vs 一级字表：老app 3499 字中 3236 字在一级字表内；一级字表有 264 字老app没有；老app另有 263 字不在一级字表内。

## 五、数据缺口与二期计划

> 2026-11-03 实测 `model-3500.json` 后更新：本节旧数字（形近 1.1%、六书 30.9%）已过时，
> 下面的数字以实测为准；“有字段”不等于“人工核验完成”，质量缺口仍在。

1. **形近字辨析**（字段 present 87.3%，3055 字）：但 3007 字是“老 app codes + IDS 算法初筛”，
   人工 curated 参与的只有约 45 字，445 字完全没有。仍需人工编纂和审核，算法初筛不能直接当辨析结论。
2. **六书归类**（55.1%，1930 字；缺 1570 字）：已有的里面 1082 字是老 app struct，
   805 字是 IDS + 拼音算法推断（未人工核验），人工 curated 只有 43 字。仍需用《说文解字》部首 + 段注批量推断，
   或从汉典补充，并对算法推断做人工复核。
3. **264 个缺字**：已按 3500 字集补齐字段，其中 260 字运用链来自 CC-CEDICT（只补了组词，句 / 文待补），
   另有 4 字（玖、叁、柒、捌）运用链仍缺失。优先补这 260 字的句 / 文和这 4 字的运用链，其次补字源。
4. **字源字形图**（未接入）：甲骨文 / 金文 / 小篆字形图，来源：中研院“小学堂”、汉典（网站抓取，二期）。
   注意授权：小学堂为 CC0、Wikimedia Commons 古汉字计划为公有领域可优先用；hanziyuan、ctext 等不建议用（见根 README）。
5. **组词造句扩充**（未接入）：来源：《现代汉语词典》（商务印书馆），需先确认授权，不能直接照抄。
6. **字源可信度标注丢失**：老 app `origin.conf`（确定 2070、通行说法 1139、待查 210、空 80）未迁移进新模型，
   新模型里 `origin` 字段为 0 个；另“段注六书”字段全部为空。需把可信度迁回，并在字卡上区分“待查”。
