# newhanzi 字库数据模型（v1）

## 一、字集范围：通用规范汉字表·一级字表（3500字）

**依据**（教育部权威文件）：
- 《通用规范汉字表》（国发〔2013〕23号）：一级字表 3500 字，"主要满足基础教育和文化普及的基本用字需要，也可以作为义务教育阶段的识字标准"
- 教育部：义务教育阶段"累计认识常用汉字3500个"；普通高中语文课标总目标"认识3500个左右常用汉字"——高中不新增识字量
- **结论：高三及以下 = 一级字表 3500 字**

文件：`ziku/ziku-level1-3500.json`

## 四、覆盖率（3500字，补数据+辅助字段升维后）

| 维度 | 覆盖 | 方法与来源 |
|---|---|---|
| 读音 | 100% | gsc_pinyin.csv + Unihan kMandarin |
| 笔画 | 100% | gsc + Unihan kTotalStrokes |
| 部首 | 99.9% | gsc + Unihan kRSUnicode |
| 繁体 | 99.9% | gsc |
| 六书 | 55.9% (1958) | 老app struct 1082 + IDS声旁谐音推断 805（未人工核验）+ 教科书级curated 43 + 说文原文显性象形 25 + 说文段注 3；缺 1542 |
| 结构（独体/合体+间架） | 100% (3500) | 老app struct + cjkvi-ids 部件分解推断 |
| 字→词→句→文 | 100% (3500字有运用链；13005义项中无句594、无文9284) | 老app senses（3236字）；CC-CEDICT 260字句已全部人工原创补完（文仍待补）；玖叁柒捌4字已补大写数字原创句 |
| 笔顺动画+描红 | 100% (3500) | hanzi-writer-data（MIT）笔顺SVG全覆盖 |
| 字源 | 97.2% (3401字有字源维度；说文本身2788，段注六书4，讲解281) | 说文解字+段注（简繁映射）；老app evo 演变阶段框架；小篆字段2433字但来源系统性不可靠，见第8条 |
| 形近字 | 88.7% (3103) | 人工整理来源48字（独体易混24+部件增减24）+ 其余为老app codes + IDS同部件挖掘（算法初筛）；缺397 |
| 形声拆解 | 92.5% (3236) | 老app parts |
| 易错提示 | 73.4% (2569) | 老app misread |

补数据脚本：`ziku/build_model.py`（基线）→ `ziku/fill_gaps.py`（补缺口）→
`ziku/promote_aux.py`（辅助字段升维+切分单字文件到 `data/zika/`）。

老app字集 vs 一级字表：老app 3499 字中 3236 字在一级字表内；一级字表有 264 字老app没有；老app另有 263 字不在一级字表内。

## 五、数据缺口与二期计划

> 2026-11-03 实测 `model-3500.json` 后更新：本节旧数字（形近 1.1%、六书 30.9%）已过时，
> 下面的数字以实测为准；“有字段”不等于“人工核验完成”，质量缺口仍在。

1. **形近字辨析**（字段 present 88.7%，3103 字）：但除 48 字人工整理来源外，其余是“老 app codes + IDS 算法初筛”，
   397 字完全没有。仍需人工编纂和审核，算法初筛不能直接当辨析结论。
2. **六书归类**（55.9%，1958 字；缺 1542 字）：已有的里面 1082 字是老 app struct，
   805 字是 IDS + 拼音算法推断（未人工核验），人工 curated 只有 43 字，另有说文原文显性象形 25 字、说文段注 3 字。
   仍需用《说文解字》部首 + 段注做人工复核；说文原文从声推断错配约 3%，象形错配多因变体字头原文挪用，故不批量填。
3. **264 个缺字**：已按 3500 字集补齐字段，其中 260 字运用链来自 CC-CEDICT，句已全部人工原创补完（文仍待补），
   另有 4 字（玖、叁、柒、捌）运用链已补大写数字原创句（文留空）。
4. **字源字形图**（未接入）：甲骨文 / 金文 / 小篆字形图，来源：中研院“小学堂”、汉典（网站抓取，二期）。
   注意授权：小学堂为 CC0、Wikimedia Commons 古汉字计划为公有领域可优先用；hanziyuan、ctext 等不建议用（见根 README）。
5. **组词造句扩充**（未接入）：来源：《现代汉语词典》（商务印书馆），需先确认授权，不能直接照抄。
6. **字源可信度标注丢失 → 已修复（2026-11-03，提交 f1663b5）**：老 app `origin.conf` 已迁移进新模型
   `字源.可信度`，并在字卡上区分显示：新模型 3500 字中确定 1962、通行说法 1022、待查 185、未标注 331
   （老数据本来没标 + 老 app 没有的新字，不编造）；51 字老数据有可信度但新模型无字源维度，已补只含可信度的
   字源项，字源正文仍待补。字源维度 present 由 3346 升为 3397，但说文本身仍为 2433 字，段注六书仍全部为空。
7. **部首释义缺口 → 部分修复（2026-11-03，提交 0945d18、3748d5d、6b58dbb、d2a7774）**：241 个部首中无释义无说解由 38 条降为 15 条；
   历次均用其本字在模型或说文源中的《说文解字》原文补说解（变体填本字与变体说明，不改 has_meaning，不猜汉典链接）。
   余下 15 条（亠、乛、丷、丬、⺁、?、⺪、⺷、⺷、灬、一字头、已、龵、龺、龺、乙、龺、羽）
   多为无说文单字条目、变体对应不明、复合组名或问号占位（有、背），须人工定标准，不编造。
8. **2026-11-03 除字形图外人工项进展（字形图批量已按用户指令排除）**：说文解字 2433→2788（老app严格引文78、说文索引264、繁体字头核对13），
   段注六书 0→4（天有转注/会意两说，留人工），六书 1930→1958（显性象形25），形近 3055→3103（人工整理48），
   讲解 232→281（象形字49），运用链 CC-CEDICT 260字句全部补完、玖叁柒捌补完。仍待定标准或人工的：
   六书缺1542与805推断复核、形近缺397与初筛辨析、说文缺712、讲解缺3219、部首余15条、运用链文（9284义项无文）、
   《现代汉语词典》授权；**小篆字段系统性不可靠**：原模型已有天→七、人→搊等错误，264批新增小篆已于 cb340a2 全部撤回，
   原有小篆值未动，须可靠小篆来源重建或整体废弃该字段后由用户定。
