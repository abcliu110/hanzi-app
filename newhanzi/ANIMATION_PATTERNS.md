# 动画范式 v2.0

> **核心原则**：按内容需要**融合多种手法**，不搞一型对一招。
> 满足多个条件的就同时引入——一个知识点可以用 2-4 种手法组合。
>
> 内容分 9 型（见 CONTENT_PATTERNS.md），每型给出**首選手法组合**，再按需从技巧库叠加。
> 原则：动画只干一件事——把文字讲不清的那个关键动作演出来。
> 时长：单个动画 3-8 秒，可重播，不自动循环抢注意力。

---

## 一、9 型首選手法组合

### 1. 规律型 → 槽位点亮 + 零件替换 + 红线警示

**配什么内容**：把字句、被字句、名词、动词等有固定结构的内容。

- **槽位点亮**：把"不变"的槽位画成框，按顺序依次亮起（把字用红框突出）
- **零件替换**：固定槽位不动，只换"可变"的零件
- **红线警示**：换一个错的，框变红+打叉
- **可叠加**：隐喻动画（如"把"=手抓起宾语）、口诀锚定

### 2. 辨析型 → 对照切换 + 正误标记 + 口诀锚定

**配什么内容**：的地得、在/再、把/被等易混点。

- **对照切换**：左右两栏，点击一侧高亮，差异处用颜色标出
- **正误标记**：病句逐字显示，错处画红圈+打叉，对的打勾
- **口诀锚定**：底部出口诀帮记忆
- **可叠加**：错误后果可视化（错了会怎样演出来）

### 3. 程序型 → 步骤推进 + 路径高亮 + 连线

**配什么内容**：审题、改病句、阅读步骤、写作流程。

- **步骤推进**：步骤卡一张张翻出，每步配一句人话
- **路径高亮**：决策树上走哪条亮哪条，没走的变灰
- **连线**：步骤之间画线表示先后关系
- **可叠加**：遮罩揭示（先出问题再揭答案）

### 4. 词条型 → 结构拆分 + 演变 + 标注

**配什么内容**：识字（单字）、虚词、实词。

- **结构拆分**：字散开成部件，再合回去
- **字形演变**（只做有出处的）：甲骨文→金文→小篆→楷书
- **连线标注**：部件与功能之间连线（如形旁/声旁）
- **可叠加**：时间轴推进（演变过程）、隐喻动画

### 5. 模式型 → 符号标注 + 成员归位 + 高亮

**配什么内容**：蒙特梭利语法符号、词类划分。

- **符号标注**：句子逐词出现，每个词头上掉下对应符号
- **成员归位**：一堆词飞入各自的符号框
- **高亮**：已分类的词保持高亮，未分类的待定
- **可叠加**：拖拽组句（学生自己拖词进框）

### 6. 故事型 → 时间轴推进 + 路径绘制

**配什么内容**：诗人、文学史、朝代、汉字史。

- **时间轴推进**：横轴时间线，节点依次亮起，配一句话
- **路径绘制**：时间线自己画出来，增强过程感
- **可叠加**：遮罩揭示（关键节点先遮后揭）

### 7. 材料型 → 逐句高亮 + 声音同步

**配什么内容**：古文、诗词、名篇。

- **逐句高亮**：整段先呈现，当前讲的句子高亮，其余变淡
- **声音同步**：朗读音频与高亮句子同步
- **可叠加**：节奏韵律（平仄用视觉节奏表示）

### 8. 清单型 → 行列高亮 + 对照切换

**配什么内容**：关联词表、虚词表、意象表等表格。

- **行列高亮**：点表头整列亮，点一行整行亮
- **对照切换**：易混的两行并列对比
- **可叠加**：点击选择（点选自测）

### 9. 互动型 → 即时反馈 + 翻卡/拖拽

**配什么内容**：所有游戏、测验。

- **即时反馈**：答对绿光+符号飞入，答错红闪+正确框脉冲
- **翻卡/拖拽**：按题型选用交互方式
- **可叠加**：粒子（答对撒花，慎用）、声音同步

## 三、融合规则

1. **满足多个条件的就同时引入**：一个知识点符合 N 种手法的适用条件，就用 N 种（2-4 种为宜）
2. **先问"最难懂的那个动作是什么"**，再从库里挑
3. **手法之间要有时序**：先结构→再变化→再辨析→再记忆，不要一股脑全上
4. **3-8 秒播完**，可重播
5. **SMIL 优先**（已验证兼容 file://），复杂交互用 JS
6. **减弱动态效果时默认暂停**（实验页已加总开关）
7. **不用笔顺/练字**（全站禁令）

---

## 四、落地规则

1. **先原型后集成**：新动画先做独立 HTML 原型，用户核对通过才进 app
2. **SMIL 优先**：站内 SVG 动画用 SMIL（已验证 8 个可用），不用 JS 逐帧
3. **不抢戏**：动画默认播一次，提供重播按钮；不自动无限循环
4. **降级**：动画加载失败时静态图必须完整可读
5. **只加不减**：加动画不删文字内容
