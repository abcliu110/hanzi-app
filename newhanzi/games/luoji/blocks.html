🧱 规则积木：拼一句，看圈怎么变

点下面的词块，拼成一句「量词 + 名词 + 是 / 不是 + 名词」。拼好一句点「拼成一句」，再拼第二句——如果两句互相矛盾，两句会一起闪红。

词块

① 量词块（点一下，填进第 1 格）
② 名词块（先点填主语，再点填谓语；点第三次换掉谓语）
③ 系词块（点一下，填进第 3 格）

拼句区（点已填的格子可以清空它）

先点一块量词，再点两块名词、中间点「是 / 不是」。

预设示例（取自「三段论」专题的现成例子）

预设只装进拼句区；「演示」会直接拼出第 1、2 句，看它们怎么闪红。

欧拉图（实时变化）

拼一句，两个圈就会按这句的意思摆好：A 圈（橙）是主语，B 圈（蓝）是谓语。圈只看位置关系，不看大小。

已经拼出的句子（点一句，右边的图就画它）

    本页只判「两句能不能同时成立」，不判单句真假：比如「所有金属是导电的东西」对不对，要查知识，不是圈能说的。
    读图口诀：所有 A 是 B ＝ A 圈整个装进 B 圈；有的 A 是 B ＝ 两圈相交，重叠处就是既是 A 又是 B 的；没有 A 是 B ＝ 两圈完全分开；「不是」取反——所有 A 不是 B ＝ 两圈分开，没有 A 不是 B ＝ A 圈整个在 B 圈里。
    矛盾律：同一意义上，两句不能同时成立——一对矛盾句里，必有一句是错的。
