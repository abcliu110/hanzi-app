# 识字星球 · 逻辑区扩充（2026-11-06）写作规范

用户要求：现在逻辑内容太单薄（只有 14 个专题），从全网找最好的逻辑学资料，通俗易懂、深入浅出，补充进 app。读者是小学中高年级到初中的孩子（平板/桌面），家长也会看。

## 参考资料（按权威和适合度挑选；只作依据，不得整段照抄，必须用自己的话改写成童语）
- 统编高中语文选择性必修上册 第四单元「逻辑的力量」（发现潜藏的逻辑谬误 / 运用有效的推理形式 / 采用合理的论证方法）——国内课标口径，术语以它为准。
- 香港大学 Joe Lau《批判性思考网》Critical Thinking Web（philosophy.hku.hk/think，有中文版，CC 授权）。
- 陈波《逻辑学是什么》《逻辑学导论》；金岳霖主编《形式逻辑》。
- Copi《逻辑学导论》；D.Q. 麦克伦尼《简单的逻辑学》；布朗 & 基利《学会提问》。
- Stanford Encyclopedia of Philosophy「Fallacies」、Internet Encyclopedia of Philosophy「Fallacies」。
- Lipman「儿童哲学 P4C」、Smullyan《这本书叫什么》（骑士与无赖类谜题）。
- 科学思维：统编小学科学教材的「控制变量」「对比实验」、事实与观点（统编语文）。
用 web_search / web_fetch 实际打开查证；每个专题在 `来源` 字段列 1–3 个你真正打开过的 URL 或书目+章节。查不到依据的说法不要写。

## 输出
写一个 JSON 文件 `/workspace/work/logic_add/<你的线名>.json`：
```
{ "category": {"id": "...", "name": "..."},   // 新分类，或写已有分类 id 表示追加进去
  "items": [ <专题>, ... ],
  "quiz": { "choice": [...], "judge": [...], "spot": [...], "blank": [...] } }
```
- 专题字段完全照 `_sample_items.json` 里的样例：name, lv(1=低年级 2=中年级 3=高年级/初中), 目标, 类比, 讲解(一两句), 口诀(押韵好记), 例子(8–10 条，含 2–3 条「错例：」), 深讲(150–300 字，像好老师讲故事), 怎么认(3 步), 辨析(和最易混的专题比), 例句解析(2–3 条 {句,析}), 易错, 练习(3 题 {q,options,answer,解析}), 讨论卡{问题,提示}, 前置知识(已有或新专题名), 决策树(谬误类必填), 来源(新增字段，列表)。图示/动画可省略（另有白板线补）。
- 题库字段照 `_sample_quiz.json`：每个专题 至少 choice 4、judge 3、spot 或 blank 1；choice 题每个错项要有「误解标注」；每题都要 "point": 专题 name。
- 例子全部用孩子熟悉的生活/校园/课文/童话场景，不用政治、宗教、暴力、广告推销场景；不出现真实在世人物的负面评价。
- 答案唯一、无争议；干扰项不能也对。术语第一次出现时用括号给大白话。
- 跟已有 14 个专题不重复（见 `_sample_items.json` 的 categories 列表），可以在前置知识里引用它们。
- 写完自己用 `python3 -c "import json;json.load(open(...))"` 校验，并逐题再检查一次答案。
- 不要改 git 仓库，只写这个 JSON。最后报告：专题列表、题数、来源清单、你不确定的地方。
