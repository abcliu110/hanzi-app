# 识字星球 / 汉字 App · 前端 UI 规范

适用范围：仓库根目录静态页 + `newhanzi/` 新版汉字学习。改 UI、加页面时必须遵守。

两套皮肤并存，**不要混用变量前缀**：

| 区域 | Token 前缀 | 权威样式文件 |
|---|---|---|
| 仓库根（旧壳/字义图等） | `--xzq-*` | `xzq-theme.css` |
| `newhanzi/`（字卡/部首/古诗/语法/实验等） | `--bg` / `--card` / `--accent`…（无前缀护眼套） | `newhanzi/zika.css` 及各页内联 `:root` |

新功能优先落在 `newhanzi/`，并只使用护眼套 token。根目录维护页继续用 `--xzq-*`。

详细 token、断点与验收见：`newhanzi/FRONTEND_UI.md`。

## 共同原则

- 护眼：浅绿纸 + 柔墨，避免高饱和蓝紫与奶油高对比纸面作为主色。
- 触控目标 ≥ 44px；焦点环可见；尊重 `prefers-reduced-motion` / `prefers-color-scheme`（根目录与 newhanzi 均已支持深色时保持对比可读）。
- 只支持平板 ≥768 和桌面 ≥1200（2026-11-04 负责人决定，不支持手机），两端都必须单独验收。
- 颜色写 CSS 变量，禁止页面内散落互不一致的硬编码主色。
