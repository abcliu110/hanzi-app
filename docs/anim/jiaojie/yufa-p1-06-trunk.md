# 交接 · 语法白板第 1 期 · 06 trunk 抽骨架模板

依据：设计 §5.1、§6.4；Q3（L1 先生长再修剪，L2 修剪为主）、Q21、Q23。

## 改了什么
- `newhanzi/wb/wb-engine.js` 新增 `TPL.trunk`（约 150 行）。数据格式：
```js
// 生长 + 修剪
{ k:'trunk', lv:2, mode:'grow+prune', core:['小猫','捉','老鼠'], role:['zhu','wei','bin'],
  grow:[ { q:'哪只小猫？', ins:['胖胖','的'], before:0, role:'ding' },
         { q:'几只？', ins:['三只'], before:0, at:'far', role:'ding', keep:1, why:'num' },
         { q:'捉到没有？', ins:['住了'], after:1, role:'bu' } ],
  ask:'哪几个字是骨头？' }
// 只修剪（带保护与试剪）
{ k:'trunk', lv:2, mode:'prune', s:['弟弟','不','喜欢','吃','香菜'], role:['zhu','zhuang','wei','wei','bin'],
  keep:[{ i:1, why:'neg' }], tryCut:{ i:1, show:'弟弟喜欢吃香菜', say:'剪掉“不”，意思反了。' }, prune:{ strike:0 } }
```
- 演出顺序：骨架 / 原句出场（成分线 + 公式行）→ 每次生长：上方出问题 → 想一想 4 秒 → 新枝叶从上方落入，其余词块平移让位，括号成分线跟着块走，公式行多出一格 → 连起来读 → 路标「的 / 地 / 得」依次画枢纽圈 → 试剪（块下沉变淡 → 想一想 → 写出剪后的句子并打 ✗ → 块弹回并戴「不能剪」）→ 其他 keep 戴保护标签 → 想一想「哪几个字是骨头？」→ 枝叶与路标下沉淡出（`strike:1` 时打删除线留在原处）→ 骨架合拢、公式行缩回 → 读骨架。
- 规则：`的 / 地` 跟前一块、`得` 跟后一块；路标不画成分线；被保护块的路标一起保留；`at:'far'` 插到最外层（多层定语排序）。
- 公式行：L1 用儿童简称（谁 ‖ 干什么 + 什么），L2 / L3 用术语简称（主 ‖ 谓 + 宾）；相邻同成分的骨架词并成一格（喜欢 吃 → 谓）；主谓之间用 ‖。
- lv ≥2 时句中画 ‖（主谓分界，排版多留 26px）。
- 排版全在构建时用 `textW` 算好，不调用 getBBox。
- `tools/wb/selftest.py` 增加两个 trunk 幕（含 far 插入、得字补语、数量词保护、strike、试剪），检查确定性与收尾骨架顺序。

## 已知问题
- 公式行的分隔符随步骤整行替换（淡入），不做逐格滑动。
- 一幕最多约 13 个字 / 8 块（44 号字）可放下；更长的句子要 `size` 调小或拆幕。
- 问题文字（q）在居中上方，与 `h` 标题同用时位置 168，未测三行以上。
