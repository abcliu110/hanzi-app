## Q20 处理（设计 §10 Q20）
按内容稿交接 `yufa-neirong-01-jushi.md` 的核实结论：「我把一本书看完了」判错**不成立**（无定把字句是受限的边缘格式，不是病句；陶红印、张伯江 2000，《中国语文》第 5 期）。
- 删掉原 fix 幕（把「一本书」圈错打 ✗）。
- 改为 L2 对照幕「“把”后多是知道的那个」：这本书（自然）/ 一本书（单说不太自然，放进上下文能说），**不用错色、不打 ✗**。
- 原 fix 幕的位置换成真正不成立的例子：可能补语不能进把字句（✗我把衣服洗不干净 → 这件衣服我洗不干净），出自 data.js「易错」。
