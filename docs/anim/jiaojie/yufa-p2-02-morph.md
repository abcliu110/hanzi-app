# 交接 · 语法白板第 2 期 · 02 morph 变魔术模板

依据：设计 §5.2、§6.3（两格状态图）、§6.4（枢纽圈）、§3.4（角色 tag）、Q9（同学错答示范，默认允许）、Q10（L1 空框 + ？，L2 起 ∅）。

## 改了什么
`newhanzi/wb/wb-engine.js` 新增 `TPL.morph`（约 140 行，基于 01 的公共 `Row` / `layG`）。数据格式：
```js
{ k:'morph', lv:2, h:'把字句变被字句',
  from:[ {id:'A', w:['茂密的','树林'], tag:'动手的'}, {id:'h1', w:['把'], hub:1},
         {id:'B', w:['太阳'], tag:'被动手的'}, {id:'V', w:['遮住了']} ],
  to:  [ 'B', {id:'h2', w:['被'], hub:1}, 'A', 'V' ],   // 字符串 = 搬 from 里的块；新对象 = 新块落入；from 里没出现在 to 的块淡出
  ask:'变成被字句，谁搬到前面？',
  wrongTry:{ drop:['茂密的'], say:'“茂密的”丢了。' },    // 可选：同学错改
  roleTo:{ B:'zhu' },                                     // 可选：变换后画成分线，对照上方角色标签
  state:{ a:'太阳亮亮的', b:'太阳被挡住了', ok:true },     // 可选：前后两格状态图（ok:false 打 ✗）
  ok:true }
// 失败变换：ok:false + say（原因，必填，lint R9）+ 可选 note（写在句下）
```
演出顺序：
1. 读原句；多词块（名词短语）描叙事灰虚线框，表示「这是一整块」；上方出 `tag` 角色标签。
2. 枢纽词（`hub:1`）先画枢纽圈。
3. （可选）同学错改：同样的变换但只搬中心语，`drop` 里的词掉在原处下方 → 想一想「这样搬对吗？」→ 错误圈 + ✗ → 圈和 ✗ 收起，退回原句。
4. 想一想 `ask` → 整块弧线换位（左移走上弧、右移走下弧），原位留虚线空位（L1 空框 + ？，L2/L3 ∅），落定后空位收起；旧枢纽淡出、新枢纽从上方落入并画枢纽圈；块上的 tag / 外框跟着中心语一起走。
5. 读新句：成功打 ✓；失败时想一想「能这么说吗？」→ 全句抖动（确定性正弦）→ ✗ + 原因 → ✗ 收起，退回原句。
6. （可选）`roleTo` 成分线、`state` 两格状态图。
- 排版：块内间距 0.14 字号、块间 36，构建时用 `layG` 算好；不调用 getBBox。
- `tools/wb/selftest.py` 增加两幕 morph（含错改、roleTo、state、失败退回），检查收尾语序「太阳 被 茂密的 树林 遮住了」、失败后退回原句、确定性。

## 已知问题
- 一行最多约 12 字（44 号）；更长要 `size` 调小。
- 错改时掉下去的词与新位置的词可能在横向上部分重叠（掉下 72px，纵向不压字）。
- `roleTo` 的成分线画在最终位置上，之后不再移动（只在收尾用）。
